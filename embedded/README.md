# Embedded Systems

This directory is for small, focused embedded programming experiments and notes.

## Learning progression

The order below is a guide—not a claim that every topic has already been completed.

1. C fundamentals: types, functions, arrays, pointers, structs
2. Bitwise operations and register-oriented thinking
3. GPIO and digital input/output
4. Timing, delays, and PWM
5. ADC and sensor readings
6. UART serial communication
7. I²C and SPI
8. Interrupts and event-driven design
9. State machines
10. Hardware debugging and basic testing

## Experiment format

Each experiment should ideally include:

- **Objective** — what is being tested
- **Hardware** — board and components
- **Connections** — pin map or circuit diagram
- **Code** — source and any required libraries
- **How to run** — build/upload steps
- **Observed result** — what actually happened
- **Troubleshooting** — issues encountered
- **Next step** — one realistic improvement
