# Digital Logic

This directory will hold digital logic exercises, circuit simulations, and notes.

## Suggested progression

- Number systems and binary arithmetic
- Boolean algebra and simplification
- Logic gates and truth tables
- Combinational circuits: adders, multiplexers, decoders, encoders
- Sequential circuits: latches, flip-flops, counters, registers
- Finite-state machines
- Timing diagrams and propagation delay
- Introduction to HDL implementation

## Documentation standard

For each exercise, record the problem, truth table or state diagram, implementation, simulation result, and a short explanation of what was learned.

Only completed and checked work will be listed as completed.
